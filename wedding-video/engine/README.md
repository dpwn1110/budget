# 영상 엔진 사용법

1. 이 `engine` 폴더를 통째로 컴퓨터에 둔다.
2. `index.html`을 **크롬**으로 연다 (더블클릭 또는 크롬 창에 끌어다 놓기).
3. ① 노래 파일, ② 사진 폴더를 고른다. 사진은 컴퓨터 밖으로 나가지 않는다.
4. ▶ 재생으로 확인하고, ③ MP4로 저장을 누른다. 저장 중에는 창을 닫지 않는다.

## 사진 폴더 구조
```
사진/
  00-opening/       봉투에서 나오는 사진
  01-baby-yechan/   예찬 아기 사진
  01-baby-hyein/    혜인 아기 사진
  02-meet/          만남
  03-dating/        데이트 (파일 이름 순서대로 나온다)
  05-wedding/       웨딩 사진
  handwriting/      손글씨 사진
  assets/           소품 이미지 (이름이 정해져 있다. ASSETS.md 참고)
```
