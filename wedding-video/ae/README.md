# AE 제작 키트 사용법

`build.jsx`는 After Effects에서 실행하면 식전 영상 프로젝트의 뼈대를 자동으로 만드는 스크립트다.
장면 11개, 가사 48줄, 마디 마커, 사진 배치, 기본 움직임이 곡의 박자에 맞춰 들어간다. 그 위에서 디자인을 다듬으면 된다.

## 1. 서체 설치 (무료, Google Fonts)
| 쓰임 | 서체 | PostScript 이름 |
|---|---|---|
| 스크립트 (이름, 가사 일부) | Pinyon Script | PinyonScript |
| 영문 세리프 | Cormorant Garamond (Regular, Italic) | CormorantGaramond-Regular / -Italic |
| 작은 산세리프 | Inter | Inter-Regular |
| 한글 | Gowun Batang | GowunBatang-Regular |

설치하지 않아도 스크립트는 돌아간다. 없는 서체는 AE가 다른 서체로 바꾸고, 끝에 목록을 알려 준다.

## 2. 사진 폴더 준비
사진 폴더 하나 안에 아래 이름의 폴더를 만든다. **파일 이름 순서대로** 화면에 나온다 (`01.jpg`, `02.jpg`…).
사진이 모자라면 처음부터 다시 돌려 쓰고, 폴더가 없으면 회색 자리표시가 들어간다.

| 폴더 | 장면 | 권장 장수 | 들어가는 사진 |
|---|---|---|---|
| `02-baby-yechan` | 오프닝, 어린 시절 | 2 | 신랑 아기 사진. 첫 장은 오프닝 봉투에서 올라와 앨범으로 이어진다 |
| `02-baby-hyein` | 오프닝, 어린 시절 | 2 | 신부 아기 사진. 첫 장은 오프닝 봉투에서 올라와 앨범으로 이어진다 |

- 사진은 JPG나 PNG로. HEIC는 AE가 못 읽는다.
- 휴대폰 사진은 회전 정보만 있고 실제로는 누워 있을 수 있다. 사진 앱에서 한 번 저장하거나 JPG로 내보내면 바로 선다.
- 소품은 있는 것만 넣으면 된다. 없는 소품은 단색이나 도형으로 대신 그린다.

## 3. 실행
1. AE에서 **새 프로젝트**를 연다.
2. `File > Scripts > Run Script File...` 에서 `build.jsx`를 고른다.
3. 노래 파일을 고르고, 사진 폴더(위 폴더들이 들어 있는 폴더)를 고른다.
4. 1–2분 뒤 `00 MASTER` 컴포지션이 열리고, 결과 요약이 뜬다.

사진이나 소품을 바꾸면 **새 프로젝트에서 스크립트를 다시 실행**하는 것이 가장 빠르다. 직접 손댄 프로젝트에 다시 돌리면 새 폴더가 하나 더 생길 뿐 기존 것을 지우지 않는다.

## 4. 만들어지는 구조
- `00 MASTER`: 노래, 장면 프리컴프 11개, 마커 null, 필름 그레인 조정 레이어
- 마커 null: **마디 번호**(`bar 24`)와 **가사**(`12. Will you be mine forever?`)가 마커로 찍혀 있다. 컷과 움직임을 맞출 때 쓴다.
- `장면/` 폴더: 장면마다 프리컴프. 각 프리컴프 안에도 가사·마디 마커 null이 있다.
- 사진 한 장은 **그림자 + 인화지 + 사진** 세 레이어다. 움직임은 `인화지`에 주면 나머지가 따라온다.
- 가사 레이어는 그 줄이 불리기 0.1초 전에 나타나서 다음 줄 직전에 사라진다. 타이밍을 바꾸려면 레이어를 마커에 맞춰 밀면 된다.

## 5. 이 스크립트가 확인된 범위
AE가 없는 환경에서 만들었다. 가짜 AE 환경(`tools/ae_mock_run.js`)에서 끝까지 실행해 오류가 없는 것은 확인했지만, **실제 AE에서는 이번이 첫 실행**이다. 오류 창이 뜨거나 요약에 "오류"가 보이면 그 문장을 그대로 보내 주면 고친다. 한 장면에서 오류가 나도 나머지 장면은 만들어진다.
