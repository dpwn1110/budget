# 실험: 나 중심 지도 (me-centered)

`mailtrace/viewer.html`의 사본에 **서울(나)을 가운데 둔 방위등거리도법** 지도를 더한 시제품입니다.
원래 뷰어는 그대로 두었습니다.

- 가운데에서 잰 거리와 방향이 실제 거리·방위 그대로입니다. 점선 고리는 나에게서 5,000 km마다, 가장자리 원은 지구 반대편(약 20,000 km)입니다.
- 첫 화면이 이 지도로 시작합니다. 오른쪽 아래 동그라미로 나 중심 → 지구본 → 평면을 오갑니다.
- 나침반처럼 천천히 돌고, 끌면 나를 축으로 돌립니다. 확대한 뒤에는 끌어서 옮깁니다.

열기: 이 폴더의 `viewer.html`을 브라우저로 엽니다. 쓰는 `messages.json`은 같습니다.

이 파일은 원래 뷰어의 사본이라, 원래 뷰어를 고쳐도 여기에는 저절로 들어오지 않습니다.
