# from@email.map — 의논용 요약 (일반 Claude에 붙여 넣기)

## 무엇인가
Gmail Takeout에서 받은 내 메일(최근 30일)의 헤더와 HTML을 읽어, 메일 한 통이 어디서 출발해
어떤 회사의 서버(데이터센터·발송 서비스)를 거쳐 나에게 왔는지, 열면 추적 픽셀이 어디로 ‘읽음’ 신호를
보내는지를 지구본 위에 그리는 작업. 주제는 "internet map" — 내 받은편지함이 그리는 인터넷 지도.

## 구성
- `parse_mbox.py` (Python, 내 컴퓨터에서 실행) → `messages.json`
  옵션: `--geo-city/--geo-asn`(DB-IP 위치), `--days`, `--me`(내 주소가 추적 주소에 숨었는지), `--redact`(전시용 가림)
- `viewer.html` 파일 하나 (HTML+CSS+JS, 프레임워크·외부 라이브러리 없음, 파일로 바로 열림)
  - 첫 화면: 데이터 없으면 도는 지구본 + 소개 + 내 위치 고르기 + messages.json 만드는 법 + ‘예시로 보기’(가상 메일 44통)
  - Globe(랜딩): 지구본 위 관계도. 4단계 이야기(요약 → 출발한 곳 → 거쳐 간 서버 → 열면 나가는 신호) 후 직접 둘러보기.
    왼쪽 기호 버튼(나·발송 서비스·출발 위치·보낸 회사·추적 도메인·DC), 아래 숫자 칸, 오른쪽 아래 지구본/평면 전환
  - Analysis: 통계, 어디서 출발했나, 관계도(큰 판, 확대·이동, 팝업)
  - Archive: 정렬되는 메일 목록, 메일 상세(경유 경로 지구본, 연결되는 도메인)
  - KR/EN 두 언어

## 지켜야 할 규칙
- 보안: 메일 속 이미지·링크·추적 픽셀을 절대 불러오지 않음(주소는 글자로만). 외부 요청 전부 차단(CSP).
  파일은 브라우저 안에서만 읽음. 개인 메일 데이터는 저장소에 올리지 않음.
- 글꼴: Pretendard 하나. 보이는 층(사람이 읽는 메일: 이름·제목·문장) 400 / 숨은 층(기계의 흔적: 서버·IP·도메인·시각·개수) 300, 작게 /
  틀(메뉴·버튼·칸 이름) 400 작게 대문자 / 큰 숫자 300 크게.
- 색: 검은 바탕, 흰 글자·선. 색은 의미가 있을 때만 — 빨강 = 나에게서 새어 나가는 신호(추적).
- 지구본 랜딩은 유지 (Lombardi식 종이 보기, 나 중심 방위등거리 지도는 시험해 보고 뺐음).

## 실험 방식
실험은 `mailtrace/lab/playground/viewer.html`(완성본의 사본)에서만 한다. 완성본은 그대로 둔다.
