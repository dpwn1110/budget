# 실험실 (playground)

`mailtrace/viewer.html`(지금 쓰는 완성본)을 그대로 복사한 실험용 파일입니다.
여기서 마음껏 바꿔 보고, 마음에 드는 것만 나중에 완성본으로 옮깁니다. 완성본은 건드리지 않습니다.

- 열기: 이 폴더의 `viewer.html`을 브라우저로 엽니다. 쓰는 `messages.json`은 같습니다.
  (폴더가 달라 브라우저 저장이 따로라, 처음 한 번은 파일을 다시 넣거나 ‘예시로 보기’를 누르세요.)
- 일반 Claude와 의논할 때는 `BRIEF.md`를 붙여 넣으면 프로젝트 맥락을 한 번에 전할 수 있습니다.
- 바꾼 내역은 아래에 한 줄씩 적어 둡니다.

## 바꾼 내역
- 선택(부분 집합) 하나로 합침: Analysis의 숫자·퍼센트·도표 행, 지구본과 관계도의 모든 기호·선이 같은 '메일 묶음'을 고른다.
  올리면 미리 보기(나머지를 흐리게), 누르면 고르기. Analysis에서 누르면 지구본으로 간다. 흐린 것은 지우지 않는다.
- 헤더에 칩 하나: "이름  42 / 326  Archive에서 보기 →  ×". 모든 탭에 보이고, Esc나 ×로 푼다. Archive는 고른 메일만 보여 준다.
- 선택이 있으면 모든 숫자에 분모 ("26 / 44"). 메일 수(전체)를 누르면 선택이 풀린다.
- 기호·선을 눌러도 팝업은 뜨지 않는다 (목록은 칩의 'Archive에서 보기'). DC 버튼은 '데이터센터 경유' 묶음을 고르는 단추가 됐다.
- 퍼센트 세 개는 선택에 따라 다시 계산하지 않는다 (누르는 단추이므로 자기 값이 변하면 안 되고, 작은 묶음에서는 의미 없이 튄다 — 전체에 대한 주장으로 고정).
- 작은 묶음(약 15% 이하): 고른 기호와 선이 은은하게 빛나고 이름이 먼저 자리를 잡는다. 4분의 1 이하이면 지구본이 출발 위치와 나의 가운데로 0.9초 동안 돈다.
- 선 미리 보기: 투명한 히트 선 14px, 떠날 때 90ms 기다려 겹친 선 위에서 깜빡이지 않게.
- 휴대폰: 헤더는 고정이라 스크롤해도 칩이 보이고, 칩 때문에 헤더가 높아지면 내용도 그만큼 내려간다.
- 열면 나가는 신호: 메일 상세를 열 때마다, 진짜 메일 앱에서 열었다면 나갔을 요청을 그린다 (실제로는 아무것도 보내지 않음).
  나 → Google(위치 비공개) → 지구본 바깥의 원(위치 모름). 추적 픽셀 하나하나 + 열면 불러오는 제3자 도메인 하나씩.
  40ms 간격, 1초 동안 날아가고, 가늘고 옅게 남아 이 세션 동안 쌓인다. 원 위 자리는 도메인마다 고정(이 파일에서 많이 나오는 순),
  다시 가면 같은 자리에 막대가 자란다. 많이 쌓인 다섯 곳은 이름과 횟수. 지구본 모드에서만 그린다.
- 왼쪽 아래 '열어 본 메일 / 보낸 신호' (모든 탭, 새로고침하면 0). 마우스를 올리면 한 문장, 아래쪽 글에도 같은 한 문장.
- 선택과의 관계: 신호 층은 흐려지지 않는다(내가 한 일이라 받은 메일 묶음과 다른 층). 선택이 있으면 그 메일들의 도메인 자리만 더 또렷해진다.
- 상세의 연결되는 곳: '열면 연락이 가는 곳 N' / '누르면 연락이 가는 곳 N'.
- (줄이기) 나가는 선은 열 때만 날아가고 사라진다. 쉬는 지구본에는 빨간 선이 없고 원 위 눈금만 조금씩 자란다.
  눈금 이름은 마우스를 가까이 댈 때만. '보낸 신호 · 열어 본 메일 N / 전체'는 원 아래로 옮기고, 그 줄에 마우스를 올리면 한 문장.
  상세 보기: 위 설명 두 줄로(낱말 중간에서 끊기지 않게), 지도 아래 범례 짧게·조작 안내는 따로 한 줄, 왼쪽 아래 세는 칸 없앰.
- (톤·정리) 상세 보기에서는 그 메일의 신호 선이 날아간 뒤에도 남는다 (첫 화면은 그대로 순간만).
  원 위 자리는 같은 간격의 눈금으로 늘 보이고, 굵기는 같고 길이만 다르다. 원 아래는 한 줄:
  "열어 본 메일 31 / 44 · 보낸 신호 146 → 위치 모름 18곳". 상세의 범례는 지도 아래 하나로 합치고,
  '위에서 아래로…'는 경유 목록 바로 위로 옮겼다(그 목록을 설명하는 문장). 추적 줄은 '열면 연락 / 누르면 연락' 두 줄.
- 들어오는 흰 선과 해안선을 절반쯤 밝기로 낮췄다 (빨강이 가장 밝게).
- 첫 화면 지구본 뒤에 은은한 차가운 빛(파랑·청록·보라·짙은 초록, CSS 그라데이션+흐림). 데이터와 무관, 움직이지 않음,
  지구본 지름의 약 60%라 흐림까지 더해도 바깥 원에 닿지 않는다.
