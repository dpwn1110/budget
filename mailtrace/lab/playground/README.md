# 실험실 (playground)

`mailtrace/viewer.html`(지금 쓰는 완성본)을 그대로 복사한 실험용 파일입니다.
여기서 마음껏 바꿔 보고, 마음에 드는 것만 나중에 완성본으로 옮깁니다. 완성본은 건드리지 않습니다.

- 열기: 이 폴더의 `viewer.html`을 브라우저로 엽니다. 쓰는 `messages.json`은 같습니다.
  (폴더가 달라 브라우저 저장이 따로라, 처음 한 번은 파일을 다시 넣거나 ‘예시로 보기’를 누르세요.)
- 일반 Claude와 의논할 때는 `BRIEF.md`를 붙여 넣으면 프로젝트 맥락을 한 번에 전할 수 있습니다.
- 바꾼 내역은 아래에 한 줄씩 적어 둡니다.

## 바꾼 내역
- 선택(부분 집합) 하나로 합침: Analysis의 숫자·퍼센트·도표 행, 지구본과 관계도의 모든 기호·선이 같은 '메일 묶음'을 고른다.
  올리면 미리 보기(나머지를 흐리게), 누르면 고르기. Analysis에서 누르면 지구본으로 간다. 흐린 것은 지우지 않는다.
- 헤더에 칩 하나: "이름  42 / 326  Archive에서 보기 →  ×". 모든 탭에 보이고, Esc나 ×로 푼다. Archive는 고른 메일만 보여 준다.
- 선택이 있으면 모든 숫자에 분모 ("26 / 44"). 메일 수(전체)를 누르면 선택이 풀린다.
- 기호·선을 눌러도 팝업은 뜨지 않는다 (목록은 칩의 'Archive에서 보기'). DC 버튼은 '데이터센터 경유' 묶음을 고르는 단추가 됐다.
